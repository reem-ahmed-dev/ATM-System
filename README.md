# ATM System

A console-based ATM System developed in C++. The project simulates the core functionalities of an Automated Teller Machine while focusing on Object-Oriented Programming (OOP), file handling, and clean code organization.

## Features

- User Login
- Balance Inquiry
- Deposit Money
- Quick Withdraw
- Custom Withdraw
- Input Validation
- File Handling

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Console Application

## Purpose

This project was built to practice C++ programming concepts, OOP principles, and file management by creating a simple ATM simulation.
